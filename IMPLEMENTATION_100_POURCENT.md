## 🚀 DÉPLOIEMENT PRODUCTION

### 1. Migrations
```bash
cd bms/api-gateway
npm run migration:generate -- -n Phase2Complete
npm run migration:run
```

### 2. Mise à jour app.module.ts
```typescript
import { QuotesModule } from './quotes/quotes.module';
import { RevenueModule } from './revenue/revenue.module';
import { CampaignModule } from './crm/campaigns/campaign.module';

@Module({
  imports: [
    // ... modules existants
    QuotesModule,
    RevenueModule,
    CampaignModule,
  ],
})
```

### 3. Tests
```bash
npm run test
npm run test:e2e
npm run test:cov
```

### 4. Build
```bash
npm run build
docker-compose build
docker-compose up -d
```
