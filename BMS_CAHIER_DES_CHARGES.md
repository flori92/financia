## 🎯 Vision et Objectifs

**BMS** est une plateforme digitale visant à **digitaliser et formaliser** les petites entreprises informelles au Bénin.

### Objectifs Principaux

1. ✅ Permettre aux entrepreneurs de suivre et certifier leurs transactions facilement
2. ✅ Accompagner vers la formalisation (NIF, facturation électronique, conformité)
3. ✅ Offrir aux experts-comptables des missions à forte valeur ajoutée
4. ✅ Faciliter l'élargissement de l'assiette fiscale
5. ✅ Faciliter l'accès aux services financiers (banques, micro-crédit)

---

## 👥 Public Cible (4 Profils)

### 1. **Entrepreneurs Informels** 🛒
- Petits commerçants, artisans, prestataires

## 🗄️ Modèle de Données Étendu

### Nouvelles Tables

```sql
-- NIF et Formalisation
CREATE TABLE nif_requests (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  company_id UUID REFERENCES companies(id),
  status VARCHAR (pending, approved, rejected),
  nif_number VARCHAR UNIQUE,
  documents JSONB,
  submitted_at TIMESTAMP,
  approved_at TIMESTAMP,
  created_at TIMESTAMP
);

-- Scoring Bancaire
CREATE TABLE credit_scores (
  id UUID PRIMARY KEY,
  company_id UUID REFERENCES companies(id),
  score DECIMAL(5,2), -- 0-100
  factors JSONB,
  certified_by UUID REFERENCES users(id), -- comptable
  valid_until DATE,
  created_at TIMESTAMP
);

-- Micro-Crédit
CREATE TABLE loan_applications (
  id UUID PRIMARY KEY,
  company_id UUID REFERENCES companies(id),
  bank_id UUID,
  amount DECIMAL(15,2),
  duration_months INT,
  status VARCHAR,
  credit_score_id UUID REFERENCES credit_scores(id),
  approved_amount DECIMAL(15,2),
  interest_rate DECIMAL(5,2),
  created_at TIMESTAMP
);

-- Déclarations Fiscales
CREATE TABLE tax_declarations (
  id UUID PRIMARY KEY,
  company_id UUID REFERENCES companies(id),
  period_start DATE,
  period_end DATE,
  declaration_type VARCHAR,
  data JSONB,
  status VARCHAR (draft, submitted, validated),
  submitted_to_dgi_at TIMESTAMP,
  dgi_reference VARCHAR,
  created_at TIMESTAMP
);

-- Certification Comptable
CREATE TABLE certifications (
  id UUID PRIMARY KEY,
  company_id UUID REFERENCES companies(id),
  accountant_id UUID REFERENCES users(id),
  period_start DATE,
  period_end DATE,
  certification_type VARCHAR,
  digital_signature TEXT,
  certificate_url TEXT,
  created_at TIMESTAMP
);

-- Gamification
CREATE TABLE badges (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  badge_type VARCHAR,
  earned_at TIMESTAMP,
  description TEXT
);

CREATE TABLE user_points (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  points INT DEFAULT 0,
  level VARCHAR,
  updated_at TIMESTAMP
);

-- OCR Transactions
CREATE TABLE ocr_scans (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  image_url TEXT,
  extracted_data JSONB,
  confidence_score DECIMAL(5,2),
  status VARCHAR (pending, validated, rejected),
  transaction_id UUID REFERENCES invoices(id),
  created_at TIMESTAMP
);

-- USSD Sessions
CREATE TABLE ussd_sessions (
  id UUID PRIMARY KEY,
  phone_number VARCHAR,
  user_id UUID REFERENCES users(id),
  session_data JSONB,
  status VARCHAR,
  created_at TIMESTAMP
);
```

## 🔗 API Endpoints Ajoutés

### NIF & Formalisation
```
POST   /api/v1/nif/request          # Demander NIF
GET    /api/v1/nif/status/:id       # Statut demande
PATCH  /api/v1/nif/:id/approve      # Admin: Approuver
GET    /api/v1/nif/verify/:number   # Vérifier NIF
```

### Scoring & Crédit
```
GET    /api/v1/scoring/:companyId   # Obtenir score
POST   /api/v1/loans/apply          # Demander crédit
GET    /api/v1/loans                # Lister demandes
PATCH  /api/v1/loans/:id/approve    # Banque: Approuver
```

### Déclarations Fiscales
```
POST   /api/v1/tax/declare          # Déclarer
GET    /api/v1/tax/pre-fill         # Pré-remplissage
POST   /api/v1/tax/submit-dgi       # Soumettre DGI
GET    /api/v1/tax/history          # Historique
```

### Certification Comptable
```
POST   /api/v1/certify              # Certifier période
GET    /api/v1/certify/pending      # Validations en attente
POST   /api/v1/certify/validate     # Valider transaction
```

### OCR
```
POST   /api/v1/ocr/scan             # Scanner document
GET    /api/v1/ocr/:id              # Résultat OCR
PATCH  /api/v1/ocr/:id/validate     # Valider données
```

### Gamification
```
GET    /api/v1/badges               # Mes badges
GET    /api/v1/points               # Mes points
POST   /api/v1/badges/award         # Attribuer badge
```
