## 🔄 **MIGRATION FACILE**

### **De GPT-4 vers Llama**
```bash
# 1. Backup données
cp .env .env.backup

# 2. Configurer Llama
echo "TOGETHER_API_KEY=your-free-key" >> .env

# 3. Tester
node test-free-llama.js

# 4. Déployer
git add . && git commit -m "Switch vers Llama GRATUIT"
```

### **De Llama vers GPT-4**
```bash
# 1. Ajouter clé OpenAI
echo "OPENAI_API_KEY=sk-your-key" >> .env

# 2. Utiliser endpoints /api/v1/ai/ (payants)
# 3. Garder Llama en backup (/api/v1/ai/free/)
```
